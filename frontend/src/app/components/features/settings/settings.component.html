HMAC-SHA256 Signature Verification Guide

Every outbound event webhook dispatched by Futane Agro ERP includes a cryptographic cryptographic signature header: X-Futane-Signature. Use your webhook signing secret to verify authenticity.

HEADERS TRANSMITTED WITH EACH EVENT
X-Futane-Signature: sha256=a1b2c3d4e5f6...
X-Futane-Event: INVOICE_CREATED
Content-Type: application/json
User-Agent: Futane-ERP-Webhook-Dispatcher/1.0
VERIFICATION CODE SAMPLES
NODE.JS / EXPRESS:
const crypto = require('crypto');

function verifyFutaneWebhook(rawBody, signatureHeader, secret) {
  const hash = crypto.createHmac('sha256', secret)
                     .update(rawBody)
                     .digest('hex');
  const expected = `sha256=${hash}`;
  return crypto.timingSafeEqual(Buffer.from(signatureHeader), Buffer.from(expected));
}
PYTHON / FLASK / FASTAPI:
import hmac, hashlib

def verify_futane_webhook(raw_body_bytes, signature_header, secret):
    expected = "sha256=" + hmac.new(secret.encode(), raw_body_bytes, hashlib.sha256).hexdigest()
    return hmac.compare_digest(signature_header, expected)
